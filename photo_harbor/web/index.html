        1 · Server and keys

        Server–

        Each person's Shortcut uses their own key as [Key] below, so their photos go to their own profile. Send the server and key to their iPhone (AirDrop or a note) so they can be pasted, not typed.

        My account

        Changing it signs you out on your other devices.

        This PC

        Harbor opens minimised and starts the server right away, so phones can sync without anyone opening it. The same setting is in the Harbor window.

        2 · Shortcut “Harbor Sync”

        In the Shortcuts app tap +, name it Harbor Sync and add these actions in order.

        1. Get Network Details → Wi-Fi, Network Name. Then If Network Details is not your home Wi-Fi name → Stop This Shortcut. End If.
        2. Get Contents of URL [Server]/api/sync/start. Method POST, header X-Harbor-Key = [Key]. Then Get Dictionary Value since → Get Dates from Input → Set Variable Since. Get Dictionary Value started_at from the same result → Set Variable StartedAt.
        3. Find Photos where Creation Date is after Since, sorted by Creation Date, oldest first.
        4. Repeat with Each item in Photos:
          1. Generate Hash SHA256 of Repeat Item → Set Variable Hash.
          2. Get Contents of URL [Server]/api/has?sha256=[Hash] (GET, same key header) → Get Dictionary Value answer.
          3. If answer is not yes: Get Name of Repeat Item; Format Date Creation Date of Repeat Item as ISO 8601; Get Contents of URL [Server]/api/upload, POST, headers X-Harbor-Key = [Key], X-Name = Name, X-Sha256 = Hash, X-Taken = Formatted Date, Request Body File = Repeat Item. Get Dictionary Value answer; If it is not yes → Add to Variable Failures.
        5. If Failures does not have any value → Get Contents of URL [Server]/api/sync/done, POST, same key header, Request Body JSON started_at = StartedAt.

        If anything failed, the sync is not marked done, so the next run tries those photos again. Photos already on the PC are only hashed, not re-sent.

        3 · Run it automatically

        Shortcuts → Automation → + → choose the trigger → Run Immediately → Harbor Sync.

        • Wi-Fi: your home network. Runs when she gets home.
        • Charger: is connected. Sends what she took while already at home.
        • Time of Day (optional): e.g. 12:00, 18:00 and 22:00.

        4 · Shortcut “Harbor Cleanup” (free up space)

        1. The same Wi-Fi check as step 1.
        2. Adjust Date: Current Date, subtract 30 days. Find Photos where Creation Date is before Adjusted Date.
        3. Repeat with Each: Generate Hash SHA256; Get Name; Get Contents of URL [Server]/api/has?sha256=[Hash]&name=[Name]&report=1; Get Dictionary Value answer. If answer is yes → Add to Variable Safe. Otherwise → the same upload request as in Harbor Sync (it is kept on the phone this time).
        4. If Safe has any value → Delete Photos Safe. iOS asks once to confirm.

        Only photos the PC has just re-hashed and found intact are deleted. They stay in Recently Deleted for 30 days. With iCloud Photos on, deleting also removes them from iCloud.
