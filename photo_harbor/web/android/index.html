Harbor for Android

Send new photos and videos from this phone to your Harbor PC over home Wi-Fi. Nothing is deleted from the phone.

Download Harbor.apk

Android 8 or newer. The APK is signed for sideloading, not a Play Store release.

Install

  1. Open this page on the Android phone, tap Download Harbor.apk, and allow installation from this browser when Android asks.
  2. Open Harbor and enter the server address shown in the Harbor window, for example http://192.168.1.10:8642.
  3. Enter the key for your profile. The main profile manages people under Setup → Server and keys.
  4. Press Sync now and allow photos and videos. The first sync may take a while.

Background sync

Tick Sync every 6 hours in the background to let Android send new items on Wi-Fi. The app uses the same hash-first protocol as the iPhone Shortcut: each file is checked with /api/has and only uploaded when it is new.

Use this only on your home network. Harbor is plain HTTP and must not be exposed to the public internet. Back to the gallery
